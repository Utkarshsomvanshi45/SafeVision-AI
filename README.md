# Safe Vision AI

Safe Vision AI is an enterprise-grade industrial safety monitoring platform designed for real-time CCTV analytics, PPE compliance detection, intelligent incident management, and automated alert workflows.

## Features

- Real-time PPE detection
- Industrial CCTV monitoring
- AI-powered compliance automation
- Incident management
- Alert escalation system
- Real-time dashboard
- Email notifications
- Multi-camera support

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- PostgreSQL
- WebSockets

### AI Stack
- YOLO
- OpenCV
- PyTorch
